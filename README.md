## Як змінити тексти, імена, цитати

Відкрий **`data.json`** і редагуй прямо в GitHub:

### Вчителі
```json
"teachers": [
  {
    "id": 1,
    "name": "Іваненко Оксана Василівна",   ← змінюй ім'я
    "subj": "Математика",                  ← змінюй предмет
    "thanks": "Текст подяки...",            ← змінюй подяку
    "cat": "current",                       ← current / past / other
    "photo": "teachers/math.jpg"            ← шлях до фото
  }
]
```

### Піни на карті — позиція в %
```json
"pins": [
  {
    "floor": 2,          ← поверх (1, 2 або 3)
    "x": 45,             ← позиція зліва (0–100%)
    "y": 55,             ← позиція згори (0–100%)
    "room": "Наш клас",  ← назва місця
    "desc": "Опис...",   ← текст спогаду
    "photo": "photos/map_klas.jpg"  ← фото місця
  }
]
```

### Змінити музику або відео
```json
"music": "music/song.mp3",
"video": "video/class.mp4"
```

## Як завантажити фото/відео/музику на GitHub

1. Відкрий папку (наприклад `photos/`)
2. Натисни **"Add file"** → **"Upload files"**
3. Завантаж файл
4. Натисни **"Commit changes"**

Через ~1 хвилину сайт оновиться автоматично! ✅
